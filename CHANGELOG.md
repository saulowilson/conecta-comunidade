# Histórico de versões

## 1.1.0 — 2026-09-09

- Acrescenta controle de alto contraste no submenu, com estado ARIA, cores e bordas reforçadas.
- Mantém as funcionalidades anteriores; a alteração compatível incrementa a versão minor.

## 1.0.0 — 2026-09-09

Primeira entrega acadêmica da Conecta Comunidade, ONG fictícia de inclusão digital.

- Páginas HTML semânticas, formulário demonstrativo e SPA com módulos ES.
- Sistema CSS responsivo, menu mobile, modal e mensagens de validação.
- Preferências opcionais limitadas ao perfil e ao projeto de interesse.
- Build com esbuild, cinco testes automatizados aprovados e quatro HTMLs sem mensagens no W3C.
- Inspeção no Chrome em desktop e com viewport configurado para 390 × 844. As dimensões das imagens capturadas podem variar por escala e área útil do navegador.
- Revisão assistida do build no pull request #1; nenhum bloqueio técnico identificado.

O versionamento começou após a implementação inicial local. O histórico registra as alterações reais realizadas a partir desse momento.
